# Input

Inputs take short single-line text; 28px tall on `surface-2` with a 1px `border`.

Padding `space-3`, radius `radius-sm`, value text 13px/400 `text-primary`, placeholder `text-tertiary`. Hover: `border-strong`. Focus: border and 1px ring in `focus` (no glow). Error: `danger` border plus a `danger` help line saying how to fix it. Label above in `small` `text-secondary`, help text below in `small` `text-tertiary`, gap `space-1`; fields in a form are `space-4` apart.

Inline editing (issue titles, property values) uses no visible border until hover or focus. Search inputs carry a 16px search icon and a `/` Kbd hint on the right. Textareas follow the same rules with `body` text and 8px vertical padding.
