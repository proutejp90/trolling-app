# SidebarItem

SidebarItem is one navigation link in the app sidebar: 28px tall, 16px icon, `ui` label.

Default: label `text-secondary`, icon `text-tertiary`. Hover: `surface-3` fill, label `text-primary`. Active (current view): `accent-soft` fill, label `text-primary`, icon `accent-text`. Radius `radius-sm`, padding `space-2`, gap `space-2`. Counts and shortcuts sit right-aligned in `small` `text-tertiary`.

The sidebar (`sidebar-width` 240px, `surface-1`, `border-subtle` right edge, padding `space-2`) stacks: workspace switcher, search, personal items (Inbox, My issues), then groups under `micro` section labels in sentence case. Groups collapse with a chevron that appears on hover. `[` toggles the whole sidebar.
