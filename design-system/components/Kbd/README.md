# Kbd

Kbd shows a keyboard shortcut next to the action it triggers.

18px tall, min-width 18px, `radius-xs`, 1px `border` on `surface-2`, mono 11px in `text-secondary`. Combos are separate keys with a `space-1` gap (⌘ K, not ⌘K). Sequences use the word "then" in `text-tertiary`. Show ⌘ on macOS and Ctrl elsewhere. Every menu item, command palette item and tooltip for an action with a shortcut shows its Kbd right-aligned.
